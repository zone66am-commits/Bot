# بوت مسلسل واحد — اشتراك إجباري بقناتين

القناتان: https://t.me/C9_9P و https://t.me/gamesps4i  
المدير: `578870514`

## التشغيل
1. أنشئ بوتاً من @BotFather وخذ التوكن، ولا تشاركه.
2. أضف البوت مشرفاً في القناتين ليتمكن من فحص عضوية المستخدمين.
3. ثبت Python 3.10+ ثم نفذ `pip install -r requirements.txt`.
4. انسخ `.env.example` إلى `.env` وضع التوكن الحقيقي في `BOT_TOKEN`.
5. على Linux/macOS: `set -a; source .env; set +a; python bot.py`.
   على Windows PowerShell عيّن متغيرات البيئة من ملف `.env` ثم شغل `python bot.py`.
6. أبق الجهاز أو الاستضافة قيد التشغيل.

## إدارة المسلسل
- `/admin` تعليمات الإدارة.
- `/settitle اسم المسلسل` تغيير اسم المسلسل الوحيد.
- `/upload` بدء استقبال الحلقات من المدير.
- أرسل الفيديوهات بالتسلسل؛ أو اكتب `#12` في وصف الفيديو لتحديد الحلقة 12 أو استبدالها.
- `/stop` إنهاء الرفع.
- `/deleteepisode 3` حذف الحلقة 3.
- `/stats` عدد المستخدمين والحلقات.
- `/start` لعرض الحلقات بعد التحقق من القناتين.

تُحفظ معرفات فيديوهات Telegram في قاعدة SQLite محلية؛ لا ترفع ملفات الفيديو مجدداً. احتفظ بنسخة احتياطية من `videos.db`. قد تفرض تيليجرام حدوداً على أحجام الفيديوهات. هذه النسخة تُدار من داخل تيليجرام وليست لوحة ويب. لا يمكن سحب الفيديو الذي وصل للمستخدم بالفعل.
